# Stock Market Analysis & Price Prediction

Author: Yashika Sharma

# About the Project
This project analyzes historical Apple (AAPL) stock market data using Python and explores basic machine learning techniques for next-day closing price prediction.

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
- Scikit-learn
- Google Colab

# Project Features
- Historical stock price analysis
- 20-day and 50-day moving averages
- Daily percentage returns
- Stock volatility analysis
- Linear Regression model for next-day price estimation
- Model evaluation using MAE and RMSE
- Actual vs. predicted price visualization

# How to Run
Open `Stock_Market_Analysis.ipynb` in Google Colab and execute the notebook cells in order.

#Learning Outcomes
This project demonstrates data cleaning, exploratory data analysis, data visualization, time-ordered train-test splitting, and introductory machine learning.

# Disclaimer
This project is for educational purposes only. Predictions are experimental and are not financial advice or reliable trading signals.
